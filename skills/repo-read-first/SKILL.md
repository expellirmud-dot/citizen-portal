# Repo Read First

Use this skill before making changes in D:\citizen_portal.

## Required Discipline

Before editing:
- read PROJECT_RULES.md
- read docs/BUILD_PLAN.md
- read docs/UI_SITEMAP.md
- inspect current routes
- inspect current component/page structure
- summarize current state
- state exact files to change

## Rules

Allowed:
- repository inspection
- Serena CodeGraph for understanding
- file structure review
- scoped change planning

Forbidden:
- editing before summary
- architecture redesign
- database/schema changes unless explicitly requested
- auth changes unless explicitly requested
- adding features outside task scope
