# Frontend UI Overhaul

Use this skill for TASK 004 visual polish and civic modern UI work.

## Required Discipline

Before editing:
- inspect existing routes and pages
- identify shared layout opportunities
- preserve all current business logic
- state exact visual changes

## Rules

Allowed:
- layout improvements
- typography improvements
- spacing cleanup
- color refinement
- card/button consistency
- responsive UI improvements
- frontend-only component extraction

Forbidden:
- backend changes
- Prisma changes
- auth logic changes
- route changes
- new features
- notification integrations
- database migrations

## UI Safety Checklist

Check:
- all existing pages still render
- forms still submit
- tracking still works
- staff status update still works
- mobile layout remains usable
- npm run build passes
