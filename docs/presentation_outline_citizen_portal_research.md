# Slide 2 — ความเป็นมาและปัญหา

## ความเป็นมาและความสำคัญของปัญหา

ประเด็นปัญหา:
- การแจ้งปัญหาและคำร้องยังใช้เอกสารกระดาษ
- ประชาชนติดตามสถานะได้ยาก
- ข้อมูลกระจัดกระจายและตรวจสอบย้อนหลังลำบาก
- เจ้าหน้าที่ใช้เวลาประสานงานหลายขั้นตอน
- ขาดระบบกลางสำหรับบริหารจัดการคำร้อง

แนวทางแก้ไข:
- พัฒนาระบบคำร้องออนไลน์ผ่าน Web Application
- รองรับการติดตามสถานะแบบ Real-time
- จัดเก็บข้อมูลอย่างเป็นระบบ

Speaker Notes:
- อธิบายปัญหาของระบบเดิมในหน่วยงานราชการท้องถิ่น
- เชื่อมโยงกับความต้องการของประชาชนในปัจจุบันที่ต้องการบริการออนไลน์
- อธิบายว่าระบบนี้ช่วยลดขั้นตอนและเพิ่มความโปร่งใสได้อย่างไร

# Slide 3 — วัตถุประสงค์ของโครงงาน

# Slide 5 — สถาปัตยกรรมระบบ

## System Architecture

องค์ประกอบหลัก:
- Frontend: Next.js + React
- Backend: Next.js Route Handlers
- Database: SQLite
- ORM: Prisma
- Styling: Tailwind CSS
- Testing: Playwright

ลักษณะระบบ:
- Modern Monolithic Architecture
- Web-based Application
- Responsive User Interface

คุณสมบัติสำคัญ:
- Request Tracking
