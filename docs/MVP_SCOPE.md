# MVP Scope — Citizen Portal

## Goal
พัฒนาระบบบริหารจัดการคำร้องออนไลน์สำหรับเทศบาลตำบลด่านทับตะโก เพื่อให้ประชาชนยื่นคำร้อง ติดตามสถานะ และให้เจ้าหน้าที่รับเรื่อง/บันทึกผลได้อย่างเป็นระบบ

## MVP Features

### Citizen
- ดูหน้าแรกของระบบ
- ยื่นคำร้องออนไลน์
- กรอกข้อมูลติดต่อ
- เลือกประเภทคำร้อง
- ระบุรายละเอียดคำร้อง
- แนบรูปภาพ
- ได้รับเลขคำร้อง
- ตรวจสอบสถานะคำร้องด้วยเลขคำร้อง

### Staff
- เข้าสู่ระบบเจ้าหน้าที่
- ดูรายการคำร้องทั้งหมด
- ดูรายละเอียดคำร้อง
- เปลี่ยนสถานะคำร้อง
- บันทึกผลการดำเนินการ
- แนบหมายเหตุภายใน

### Admin / Executive
- ดูจำนวนคำร้องทั้งหมด
- ดูคำร้องตามสถานะ
- ดูคำร้องตามประเภท
- ดูรายงานพื้นฐาน

## MVP Non-goals
ยังไม่ทำในเวอร์ชันแรก:
- AI image classification
- Chatbot
- Mobile native app
- Realtime websocket
- Microservices
- Predictive analytics
- ระบบอนุมัติหลายชั้นซับซ้อน
- เชื่อมระบบราชการภายนอก

## Success Criteria
ถือว่าส่งมอบ MVP ได้เมื่อ:
- ประชาชนส่งคำร้องได้จริง
- ระบบออกเลขคำร้องได้
- ประชาชนตรวจสถานะได้
- เจ้าหน้าที่เปลี่ยนสถานะได้
- Dashboard แสดงข้อมูลพื้นฐานได้
- ข้อมูลถูกบันทึกลงฐานข้อมูลจริง
